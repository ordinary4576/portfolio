# Modern 3D Portfolio

This is a modern 3D portfolio website built using React, Three.js, and TypeScript.
It features immersive 3D interactions, responsive design, and smooth animations.

## Tech Stack
- React
- Three.js (@react-three/fiber, @react-three/drei)
- TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
